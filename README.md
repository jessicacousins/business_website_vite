# Business Website - React Landing Page

Fully responsive business website built with **React**. This landing page highlights a company’s digital services with a stylish design, smooth animations, and clear section-based navigation.

##  Live Sections

- **Hero** — Bold intro with animated headings and floating visuals.
- **About** — Describes company values like Innovation, Quality, and Collaboration.
- **Services** — Cards highlighting service categories like Web Development, UI/UX, and Strategy.
- **Contact** — Contact form with animated inputs and contact info.
- **Footer** — Lightweight footer with branding, links, and copyright.

##  Features

- Built with **React** using functional components and hooks
- One-page scroll with **smooth section navigation**
- Responsive layout (mobile-first)
- Animated scroll-in effects and floating UI elements
- Stylized buttons with glowing hover effects
- Section highlighting based on scroll position
- Contact form (non-functional but visually complete)
